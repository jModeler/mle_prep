# Day 1 — Lists, dicts, sets, tuples

**Date:** Sun 2026-05-24
**Time budget:** ~2 hours
**Goal:** Internalize the four core Python containers + their idioms, so they come out without thinking on Days 2–7.

---

## How to use this folder

1. **Read** `../SOLVING_TIPS.md` — cross-cutting guidance on timing yourself and handling clarifying questions when there's no interviewer. Read once; it applies to every day.
2. **Read** `concept_brief.md` (~20 min). It's a one-page reference — the things you should be able to glance at right before any interview.
3. **Optional deeper dive:** if anything in the brief feels hand-wavy (especially the *why* behind complexity), open `deep_dive.md`. It builds the concepts from first principles. Skip it if the brief is enough.
4. **Solve** the problems in `problems.md`, in order, against the clock. Each starter file has a timer target at the top. Write directly in the `*.py` files.
5. **Self-test** at the end (`self_test_user_items.py`) — under 5 minutes, no lookups.
6. Add a 1-line reflection to `reflection.md` (what was hard, what idiom you fumbled).

---

## How to resume in a new session (for Claude)

Tell the new session:

> Review my Day 1 solutions in `prep_days/day_1/`. Read `problems.md` for the spec and timer targets, then read each `*.py` solution and give me feedback. Focus on: (1) correctness, (2) whether I hit the timer target, (3) which Day 1 idioms I used vs. fumbled, (4) one staff-level habit I should drill on Day 2.

Then point it at `Memory/` and `PREP_PLAN.md` for context.
