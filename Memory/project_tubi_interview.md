Saisandeep is preparing for two blocking Tubi MLE interview rounds:

1. **ML Coding** (~2026-06-18) — 60 min, Python 3 on CoderPad. Themes (per the official prep PDF in `instructions/`): event stores with time-range queries, weighted sampling / recommendation logic, core ML algos from scratch (K-Means, KNN, distance metrics). Most candidates fail because they can't complete the end-to-end pipeline in 60 min.
2. **ML Breadth & Depth** (date TBD) — 60-min verbal discussion covering supervised/unsupervised, ensembles, embeddings, transformers, RAG, RLHF, learning-to-rank, etc.

The 25-day coding-round prep plan lives at `PREP_PLAN.md` (root of this repo). It's structured in four phases: DSA foundations → ML primitives from scratch → end-to-end pipeline mocks → polish.

**Why:** Recruiter feedback flagged completion under time pressure as the main failure mode — so the plan optimizes for fluency and "working-first, polish-later" muscle memory rather than breadth.

**How to apply:**
- When Saisandeep asks for help on a prep topic, default to a timed-practice framing (under X minutes, from a blank file).
- Reinforce the staff-level habits listed at the top of `PREP_PLAN.md` (clarify first, modularize, narrate trade-offs).
- If asked to invent practice problems, lean toward the three theme buckets above, not generic LeetCode.
- The breadth/depth round will need its own plan later — don't conflate the two.
